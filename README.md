# Читаем со вкусом

Отдельный статический сайт книжных путешествий. Снимок сайта MyWorld от 15.10.2026, исходный коммит `5cc78a3542e12226563668327687006ef6e1a7b7`.

## Vercel

1. В Vercel выбрать Add New → Project → репозиторий `sergey9lap-sys/book`.
2. Root Directory: корень репозитория. Framework Preset: Other.
3. Build Command: `npm run build`. Output Directory: `dist`. Настройки уже записаны в `vercel.json`.
4. Нажать Deploy. Переменные окружения и платные сервисы для сборки не нужны.

Главная открывается по `/`, архив Италии — `/italy/`. Старые пути `/book/…` перенаправляются в корень нового домена. Для архива изменён только технический base URL; дизайн, текст, фотографии и видео сохранены.

## Локальный запуск

Нужен Node.js 22 или новее. Внешних npm-зависимостей нет.

```sh
npm test
npm run build
npm run dev
```

Предпросмотр: http://127.0.0.1:4385/ . Исходники в `public/`, результат сборки в `dist/` (не хранится в Git).
