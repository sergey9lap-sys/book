# Читаем со вкусом

Отдельный статический сайт книжных путешествий. Снимок сайта MyWorld от 15.10.2026, исходный коммит `5cc78a3542e12226563668327687006ef6e1a7b7`.

## Vercel

1. В Vercel выбрать Add New → Project → репозиторий `sergey9lap-sys/book`.
2. Root Directory: корень репозитория. Framework Preset: Other.
3. Build Command: `npm run build`. Output Directory: `dist`. Настройки уже записаны в `vercel.json`.
4. Нажать Deploy. Переменные окружения и платные сервисы для сборки не нужны.

Главная открывается по `/`, архив Италии — `/italy/`. Старые пути `/book/…` перенаправляются в корень нового домена. Для архива изменён только технический base URL; дизайн, текст, фотографии и видео сохранены.

## Локальный запуск

Нужен Node.js 22 или новее. Внешних npm-зависимостей нет.

```sh
npm test
npm run build
npm run dev
```

Предпросмотр: http://127.0.0.1:4385/ . Исходники в `public/`, результат сборки в `dist/` (не хранится в Git).

## Оплата и ограничения

Счета Robokassa действующие: 4 990 Р и 8 980 Р. Они открываются в новой вкладке после подтверждения. Тестовый тариф 10 Р убран. Развёртывание на Vercel не превращает оплату в sandbox. Завершение оплаты и последующий переход в Telegram здесь автоматически не проверяются.

Оферта организатора подключена исходной ссылкой. Домен и соответствие условий прямой покупке организатор должен согласовать; сам перенос не является юридическим одобрением. В нижнем блоке — кнопка «Заполнить анкету участника», открывающая присланную Google-форму в новой вкладке. Встраивание удалено по просьбе пользователя: чужой интерфейс и ошибка входа Google не должны занимать блок сайта. При проверке 17.10.2026 Google требует вход в аккаунт; переход по кнопке сам по себе это требование не отменяет. Пробная заявка не отправлялась. Аналитика не добавлена, индексирование выключено до отдельного согласования запуска.

Секретов, токенов бота, базы, переписок и серверной конфигурации в репозитории нет. Публикация этой копии не обновляет действующий сайт `space.lpsflow.ru/book/` и не меняет MyWorld.

## Aeza: обновление уже установленной Git-копии

После установки b1b9f25 `/srv/book/current` указывает на Git-копию в `/srv/book/releases/`; nginx читает её `public/`. Для последующих обновлений можно использовать `git pull --ff-only origin main` из `/srv/book/current`, предварительно проверив чистоту рабочего дерева и сохранив копию `public/`. Node.js на этом статическом сервере для обновления не нужен.

При создании новой версии через `mktemp -d` обязательно отдельно задавать ей `chmod 755` перед переключением: по умолчанию каталог закрыт правами 700 и nginx не сможет прочитать сайт. Не применять рекурсивные 777 и не менять права всей `/srv`.
